03 - Approach

How networks and servers fit together.

layer 1-3

A server is only as good as its network

  • Users reach servers through DNS, DHCP, VLANs and routing - if any one fails, the server looks "down" even when it's running.
  • That's why I troubleshoot from the network up: cable, IP, gateway, DNS, then the server.
  • Redundancy like HSRP keeps services available when a link or switch fails.

network & server

Protecting the network and the server

  • Separate guest devices from servers with VLANs.
  • Harden switch ports with port security, DHCP snooping and DAI.
  • Encrypt site-to-site traffic and limit remote management to admins.
  • Give user accounts only the permissions they need.

people first

Support is where it all comes together

  • My labs taught me to work out whether a problem is the device, the network or the server.
  • Understanding the whole path helps find the cause faster and explain it simply.
  • Good IT should be reliable and easy for people to use.
